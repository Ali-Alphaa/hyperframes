HyperFrames

Tip: press Alt+← in Studio to come back here and open another project.

Most features are used by asking Claude. Copy a request and paste it into Claude, naming your video or project.

Where to find things in Studio

Top bar

Capture and Inspector modes, light/dark theme, Window (which panels show) and Export: render format, quality and size.

Left panel

Compositions (scenes), Assets (media files), Code and Catalog (ready-made blocks to add).

Right panel

Design: position, size, colour, text and animation of whatever you select. Layers, and Renders: your finished exports.

Timeline

Along the bottom: play, scrub, select and trim clips, zoom with the slider.

Project settings

Each project's hyperframes.json (catalog address, folder paths, media proxies). There's no screen for these: ask Claude to change them.

Studio Pack and add-ons

No buttons: ask Claude. The Features tab lists each one with a request you can copy.

Folders scanned for projects
